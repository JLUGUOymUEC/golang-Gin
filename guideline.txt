# IDP 项目架构指南

> 标记说明：`[已实现]` 表示已有代码；`[草稿]` 表示已有文件但尚未接入运行链路；`[规划]` 表示目标目录或能力。

```text
golang-Gin/
├── main.go                              # [已实现] Gin 示例入口：GET /ping
├── cmd/
│   ├── idp-gateway/
│   │   └── main.go                      # [草稿] IDP API 网关入口
│   ├── user-service/
│   │   └── main.go                      # [已实现] User gRPC 服务，监听 :50051
│   └── auth-service/
│       └── main.go                      # [草稿] 独立认证授权服务入口
│
├── internal/
│   ├── gateway/                         # [草稿] 对外 IDP 网关
│   │   ├── main.go
│   │   ├── routes/
│   │   │   └── auth_routes.go           # 登录、登出、令牌、用户资料路由
│   │   └── middleware/
│   │       ├── auth.go                  # JWT 验证
│   │       ├── rate_limit.go
│   │       └── cors.go                  # 待实现
│   │
│   ├── handler/                         # [草稿] Gin HTTP handler
│   │   ├── auth_handler.go              # 登录、注册、令牌、资料
│   │   └── user_handler.go
│   │
│   ├── user/                            # [已实现] 用户与当前认证核心
│   │   ├── main.go                      # 待实现
│   │   ├── handler/
│   │   │   └── user_grpc.go             # gRPC 请求分发
│   │   ├── service/
│   │   │   ├── user_service.go          # 用户查询与管理
│   │   │   ├── account_service.go       # 注册、资料、修改密码
│   │   │   ├── auth_service.go          # 登录、令牌、会话
│   │   │   ├── session_service.go       # 会话管理
│   │   │   └── credential_service.go    # bcrypt 密码处理
│   │   └── repository/
│   │       ├── user_repository.go       # 用户仓储接口
│   │       ├── session_repository.go    # 会话仓储接口
│   │       ├── token_repository.go      # 授权码、访问/刷新令牌接口
│   │       ├── *_model.go               # 用户、会话、令牌模型
│   │       └── dynamodb_*.go            # DynamoDB 实现
│   │
│   ├── auth/                            # [规划] OAuth2/OIDC 认证领域
│   │   ├── handler/                     # auth gRPC 或 HTTP 编排层
│   │   ├── service/                     # authorize、token、OIDC、MFA
│   │   └── repository/                  # OAuth 客户端与授权码存储
│   │
│   └── order-service/                   # [草稿] 与 IDP 无直接关系的占位服务
│
├── api/
│   ├── user/
│   │   └── user.proto                   # [已实现] UserService gRPC 契约
│   └── pb/user/
│       ├── user.pb.go                   # protobuf 生成代码
│       └── user_grpc.pb.go              # gRPC 生成代码
│
├── pkg/                                 # [规划] 可复用的 IDP 基础包
│   ├── idp/oauth2/                      # OAuth2 授权流程与校验
│   ├── idp/oidc/                        # Discovery、JWKS、Claims
│   ├── idp/mfa/                         # MFA
│   ├── jwt/                             # JWT 签发和校验
│   └── crypto/                          # 密码和随机数工具
│
├── configs/                             # [草稿] 服务配置文件
├── scripts/                             # 构建、proto 生成、Docker 脚本
├── go.mod
└── go.sum
```

## 目标调用关系

```text
客户端
  │ HTTP（OAuth2 / OIDC）
  ▼
IDP Gateway（Gin）
  │
  ├── 认证、令牌、会话 ──► Auth Service / internal/auth
  └── 用户资料与凭据 ────► User Service（gRPC）
                                   │
                                   ▼
                              DynamoDB
```

当前真正可运行的服务只有 `cmd/user-service`；认证、令牌和 DynamoDB 的领域代码虽已开始编写，但尚未由服务入口完成依赖装配和调用。
